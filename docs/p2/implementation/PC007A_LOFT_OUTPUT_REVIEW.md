## Přezkoumané integrační hranice

- **Pure loft není prázdný material proof.** I když `curve_profiles={}`, snapshot loft registry aktivuje validaci, oba raw topology/area readery i direct source→output guard. `expected_loft_surface_ids` vychází z živého registru surface feature a je oddělené od `construction_checks.lofts`. Vymazaný certifikát se nemůže vydávat za známé prázdné pokrytí. Base snapshot coverage navíc ověřuje právě jednou všechny part/surface IDs.
- **Source binding je skutečné navázání.** Kontrolují se obě aktuální profile UUID/revision, surface UUID/revision/part, source params/correspondence, scale a přepočtené intrinsic/feature digesty. Pokrytí obsahuje všechny segmenty obou profilů. `_bound_source_native` odvozuje očekávané native controls z právě těchto detached records a konkrétního canonical frame; samotná tvrzení o stejné ploše/topologii nestačí. Vlastní posun všech CUT x controls o0.125 zachová přesně plochu112, ale správně selže. Záměna source stran, feature revision, representation důkazu i skutečného anchor vertexu jsou odmítnuty.
- **PDF precision má ohraničený backend contract.** `_precise_path` ověří skutečný backend path a počet operands před přepsáním pouze číselných tokenů do17 míst bez exponentů; příkazy/order/closure zůstávají. Platí pro bound loft díly, původní planar oblouky používají svou dosavadní větev. Přesný lokální CTM vyžaduje čerstvé `q` a ověřený skutečný `cm`. Nejde o deklaraci, že17 číslic samo o sobě dokazuje správnost: následné kontroly čtou skutečné bytes a nezávisle je vážou na source controls.
- **Celá poloha a délka.** Vlastní statické source review potvrdilo, že rozdíl dvou stejně parametrizovaných L/C cest je Bernstein polynom rozdílů controls. Maximum L1 control rozdílu konzervativně kryje celou křivku; integrál normy derivace rozdílu je omezen součtem L1 délek celého difference-control polygonu. Součet jde přes celý CUT včetně closure, nikoli nová tolerance pro každý krátký segment. Source F→native representation bound se přičítá právě jednou a pouze k novému native→actual rozdílu; closing rulings mají vlastní původní délkový budget. Rotated31° loft na druhé stránce prošel vlastním skutečným exportem a správným page coverage bez mutace projektu.
- **Plocha má původní source.** Pro oba skutečné formáty se nezávisle porovnává jejich actual native area interval přímo se stejným intrinsic source intervalem. Mez je `max(.01,source_lower/1e6)`. Žádná další plná .01 rezerva za SVG a další za PDF; length/position odvozený tube guard ji nenahrazuje.

## LO-01 — drobná dokumentační nepřesnost o cold cache

Na3f4 docstring `validate_loft_snapshot` tvrdí „does not re-run the source solver“. `_bound_source_native` však používá `_bound_analysis→_analyze`; na cache miss se schválený zdrojový výpočet skutečně může zopakovat. Z cache nelze odvozovat garantovanou UI latenci. Nativní UI performance není tímto měřena ani přijata.
