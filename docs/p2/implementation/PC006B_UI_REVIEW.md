## Zdrojová kontrola a skutečné rozhodnutí UI

Receiving čára je autorská stopa na existujícím materiálu; plocha se neořezává ani nevyrábí falešný boundary pár. Kreslení určí počátek/směr a délka vychází ze skutečné zdrojové hrany/intervalu; přesný režim zůstává dostupný. Preview pracuje s klonem, region není vystřihovaný otvor. Neplatný kontakt vypne potvrzení, původní geometrii nemění. Lepicí patch dialog odděluje zdroj a příjemce a vyžaduje skutečně přiléhající materiál.

Connector dialog klonuje zdrojový stav, vrací parametry a změnu přehraje přes controller jednou; pouhé otevření nepřidává undo ani nezaokrouhluje zdrojová čísla. Vlastní obrys má pevné dva body základny, per-tab editor pracuje se sémantickým UUID. Vypnutí identity nemaže a pásek vytváří skutečný nový materiál se dvěma protikusy. Receiver side `unknown` je výslovná volba; konečné folded konflikty se nezamlčují. Návrh s takovým konfliktem lze dále upravovat, ale export dál blokuje doména.

Společný relationship výběr skutečně synchronizuje EdgePair základní formulář a nový attachment panel; attachment nezanechá starý jiný joint aktivní. Issue→relation navigace zvýrazní stejný vztah a protikus. Secondary receiver je odlišený od hlavního výběru, overlay vychází z reálného folded footprintu/regionu a vadný kontakt nezobrazuje jako platný. Vlastní native/render ověření těchto barev a ovladačů dosud chybí; autorovy offscreen path-array testy neprohlašují framebuffer za ověřený.

Změna kláves Home/F je oprava konkrétního strukturálního konfliktu: globální shortcut kradl Home z comboboxu. Připnutý kód omezuje tyto akce na canvas WidgetShortcut; skutečný Qt regression test potvrdil combo Home i viewport Home a nulovou změnu dokumentu. Není to kosmetická modernizace ani další nápověda místo opravy interakce.

`copy_source_path` je oddělený od undo snapshotu a chrání známý schema1 origin i po failed command/undo/redo. Úspěšné SaveAs z něj udělá běžnou novou kopii; doménová kontrola existujícího schema1 souboru přesto dál brání jeho pozdějšímu přepsání. To je podložené testy, nikoli tvrzení o úplné migraci všech historických modelů.
