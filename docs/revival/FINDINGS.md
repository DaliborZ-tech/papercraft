## Jak nálezy použít

Šest nových diagnostických pytestů je záměrně mimo původní `tests/` discovery: [test_diagnostic_contracts.py](../../tools/revival/test_diagnostic_contracts.py). Spouští se explicitně. Všechny aktuálně selhávají konkrétním assertion očekávané vady; žádné SKIP/XFAIL ani schované runtime chyby. Konkrétní test nelze „opravit“ přepsáním expected podle dnešní implementace. Nová panelová pipeline může mít jiná API; přenést orákulum a negativní scénář, starou omezenou větev pravdivě označit.

Původní produkce se během tohoto balíku nemění. P2 kontrakt řeší výše uvedené vady v nově podporované podmnožině; E11 vady se odkládají společně s implementací rotačních tvarů a jejich tvrzení se v P2 nepoužijí. Závažnost se tím nezmění na „opraveno“.

## Neověřené a nedoložené oblasti

OCC skutečná instalace/API, obecná topologie/díry, externí editor interoperability, fyzická stavba a další GPU/DPI varianty jsou NOT_VERIFIED. Aktuální Windows/OpenGL a nativní souborové dialogy ověřeny jsou; nelze tedy celý desktop označit jako nedostupný. Připravené digitální exporty v evidence jsou diagnostické, nevydávat je za tiskový balík pro sestavení.
